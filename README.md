# 🎓 Student Expense Tracker

A clean, minimal, and beautifully designed expense tracker built for students — powered by pure **HTML5**, **CSS3**, and **JavaScript**. No frameworks. No backend. Just elegance.

## ✨ Features

- **Track Income & Expenses** — Add transactions with description, amount, date, and category
- **Monthly Budget** — Set a budget and visualize spending with a progress bar
- **Dashboard Summary** — View total income and expenses, plus the current month's remaining budget
- **Category Breakdown** — Visual bar chart of expenses by category
- **Filter & Search** — Search by description, filter by type/category, sort by date or amount
- **14 Built-in Categories** — Food, Transport, Books, Rent, Freelance, Scholarship & more
- **Persistent Storage** — All data saved in `localStorage` (survives page reloads)
- **Fully Responsive** — Works seamlessly on desktop, tablet, and mobile
- **No Dependencies** — Zero frameworks, zero libraries, zero build tools

## 🎨 Design

Minimal and modern with a premium feel:

- **Font** — Plus Jakarta Sans
- **Palette** — Warm cream background, deep navy accents, muted earthy tones
- **Style** — Clean geometry, subtle shadows, generous whitespace, uppercase micro-labels

## 🛠 How It Works

| Feature | Implementation |
|---------|---------------|
| Data Storage | `localStorage` — all data stays in the user's browser |
| Budget Tracker | Progress bar updates dynamically; turns red when over budget |
| Filtering | Real-time search and multi-filter with sort options |
| Chart | Pure CSS horizontal bar chart — no chart library needed |
| Responsiveness | CSS Grid + media queries |
